# Scene text fonts

Scene text uses pinned Fontsource packages for Inter, Lora, Roboto Mono,
Cinzel, Noto Sans, Noto Sans SC, and Unifont. The WOFF2 files are bundled into
the renderer build so glyph selection and measurement do not depend on fonts
installed on the host or client computer. All families are licensed under the
SIL Open Font License 1.1; the full license is included alongside this notice
in `OFL-1.1.txt`.
